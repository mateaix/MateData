# MateData 首期设计

用户已批准：开源问数平台，DDD 模块化单体，JDK 25，最新稳定依赖，三小时演进式开发。

## 架构

一个 Spring Boot 进程和一个 Vue + Element Plus 前端。领域按 catalog（连接与元数据）、semantic（指标维度与业务词）、conversation（问数与结果）、harness（模型编排与执行轨迹）、identity（身份权限）组织，各自包含 domain/application/infrastructure/interfaces。共享内核仅包含标识、异常等稳定类型。先使用 Maven domain/server 两个构建模块，领域通过应用端口协作，不通过数据库跨域读取。

matehive 仅参考 DDD、SPI 和工具治理思路，重新实现；Supersonic 参考“语义检索—解析—校正—翻译—查询”的流程。不上注册中心、RPC 或分布式事务。

## 首期可验收范围

1. 内置销售数据集，离线可执行确定性语义查询；清晰标记 demo 模式，不冒充 LLM。
2. 数据源管理、连接验证、表元数据浏览；优先 H2 示例、PostgreSQL、MySQL JDBC。
3. 语义模型：数据集、指标、维度、别名，受控标识符与列白名单。
4. 自然语言问数：AgentScope Java 2.0.3 Harness 接入兼容 OpenAI 的模型配置；工具仅开放语义读取和受治理的查询。无密钥时明确提示，demo 模式独立可用。
5. SQL 仅允许经过 AST 验证的 SELECT，表列白名单、行数上限、超时、只读连接；拒绝多语句、写入、系统对象和危险函数。
6. 执行预算、步骤追踪、错误终态、历史会话、评测用例与结果；调用失败不伪造成功。
7. 身份认证与角色边界、审计记录；凭证经环境变量注入，响应不泄露数据库密码和模型密钥。
8. UI：问数工作台、数据源、语义模型、运行记录、评测和设置。中英文混合以中文产品文案为主，桌面与小屏可用。

## 数据与接口

元数据持久化使用 H2 文件库（本地单进程默认），保留迁移到 PostgreSQL 的端口。演示业务库与元数据库分离。API `/api/v1`，成功直接返回资源 JSON，错误 `{code,message,requestId}`。会话返回问题、SQL、列、行、图表提示与执行步骤。身份通过服务端会话 Cookie；前端 dev proxy 同源访问。

## 验证

领域测试覆盖语义编译与拒绝策略；集成测试真实数据库查询、持久化、身份隔离与 API；AgentScope 使用本地协议测试服务验证工具调用，不依赖外部付费模型；前端类型检查与构建；浏览器实际问数、错误态、历史和页面导航。外部 LLM 的真实质量评测需要用户的模型配置，报告明确区分协议验证与真实模型评测。

## 演进节奏

- 0–45 分钟：工具链、领域模型、演示查询、基础 UI。
- 45–100 分钟：AgentScope Harness、语义与数据源管理、持久化。
- 100–150 分钟：权限、查询防护、审计与评测。
- 150–180 分钟：端到端验收、修复、部署与贡献文档。

每阶段以构建和行为测试为准，记录实际完成范围，不将首期等同于生产认证。
