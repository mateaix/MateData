# MateData Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for independent UI implementation and review. Root executes backend integration. Track actual evidence here.

**Goal:** Deliver a runnable open-source question-to-data vertical slice and evolve governance over three hours.

**Architecture:** DDD modular monolith. Pure Java domain module and Spring Boot server adapters; Vue SPA. Domain boundaries are catalog, semantic, conversation, harness and identity.

**Tech Stack:** JDK 25, Spring Boot 4.1.1, AgentScope Java 2.0.3, Vue 3.5.43, Element Plus 2.14.6, Vite 8.3.0, TypeScript 7.0.2.

## 1. Foundation and semantic query domain

Files: `pom.xml`, `matedata-domain/pom.xml`, `matedata-server/pom.xml`, `matedata-domain/src/{main,test}/java/io/matedata/semantic/`.

- [ ] Prepare project-local JDK selection and Maven build on release 25.
- [ ] Add failing semantic compiler tests: revenue by region produces only registered identifiers; unknown metrics and dimensions are rejected; filters use JDBC parameters.
- [ ] Implement immutable semantic records and query compiler; run `mvn -pl matedata-domain test`, require zero failures.
- [ ] Add failing SQL guard tests for multi-statement, DML, unknown tables, dangerous functions and nested queries; implement restricted AST policy and verify.

## 2. Backend vertical slice

Files: server `catalog`, `semantic`, `conversation`, `identity` and `harness` packages; `application.yml`; `db/migration`.

- [ ] Integration tests start real H2 databases. Assert login, list dataset, ask “各区域销售额”, exact seeded totals, persisted run lookup, and denied unauthenticated requests.
- [ ] Implement migrations, adapters, application services and REST resources.
- [ ] Tests verify timeout, query row cap, error persistence, credential redaction and session isolation.
- [ ] Run `mvn verify` with JDK 25, commit verified milestone.

- [ ] Run `npm run typecheck`, `npm test`, `npm run build`.
- [ ] Spec review, then code-quality review; address reported issues.
