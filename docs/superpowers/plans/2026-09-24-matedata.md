# MateData Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for independent UI implementation and review. Root executes backend integration. Track actual evidence here.

**Goal:** Deliver a runnable open-source question-to-data vertical slice and evolve governance over three hours.

**Architecture:** DDD modular monolith. Pure Java domain module and Spring Boot server adapters; Vue SPA. Domain boundaries are catalog, semantic, conversation, harness and identity.

**Tech Stack:** JDK 25, Spring Boot 4.1.1, AgentScope Java 2.0.3, Vue 3.5.43, Element Plus 2.14.6, Vite 8.3.0, TypeScript 7.0.2.
